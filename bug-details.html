About This Hunt

Find security, usability, performance, and functional bugs in the target website and submit responsible reports. This environment mimics a real-world student portal, containing intentionally placed logic flaws and UI defects for you to discover.

Bug Types to Look For

Functional Bug

Broken features, incorrect logic, or unexpected behavior.

Security Bug

Potential security vulnerabilities (XSS, CSRF, insecure data).

UI/UX Bug

Visual glitches, alignment issues, or severe usability problems.

Performance Bug

Extremely slow loading times or severe memory leaks.

Compatibility Bug

Issues appearing only on specific browsers or devices.

Bug Hunt Rules

  • Only report genuine bugs that affect the user experience or security.
  • Do not intentionally damage the website or perform disruptive DDoS testing.
  • Do not access, modify, or leak private user information.
  • Provide clear reproduction steps for every report.
  • Include screenshots or screen recordings where appropriate.
  • Duplicate reports will be rejected and will not receive rewards.
  • Follow responsible disclosure practices at all times.
